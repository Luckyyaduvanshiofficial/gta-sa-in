# GTA San Andreas Modded Landing Page

## Overview
A visually striking, gaming-themed landing page promoting a heavily-modded version of GTA San Andreas. Features a modern dark aesthetic with neon accents, SEO optimization, and responsive design.

## Project Purpose
This landing page is designed to:
- Promote the modded GTA San Andreas with enhanced graphics
- Drive downloads through compelling design and clear CTAs
- Target both Indian (.in) and global (.one) audiences
- Rank for "gta san andreas download" keyword

## Tech Stack
- **Frontend**: Pure HTML5, CSS3, Vanilla JavaScript
- **Fonts**: Bebas Neue (GTA-style headers), Rajdhani (body text)
- **Icons**: Font Awesome 6.4.0
- **Server**: Python HTTP server on port 5000

## Key Features Implemented
✅ SEO-optimized with "gta san andreas download" keyword integration
