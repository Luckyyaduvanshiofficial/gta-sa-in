What You'll Need

  • Windows 7, 8, 10, or 11 (32-bit or 64-bit)
  • 8GB free hard drive space (10GB recommended)
  • 2GB RAM minimum (4GB recommended)
  • Internet connection for download
  • WinRAR or 7-Zip (free extraction software)
  • Administrator access to your PC

Pre-Installation Checklist

1. Update Windows

Ensure Windows is updated to avoid compatibility issues:

  1. Open Settings > Update & Security
  2. Click "Check for updates"
  3. Install all available updates
  4. Restart if prompted

2. Update Graphics Drivers

Latest drivers prevent crashes and improve performance:

  • NVIDIA: GeForce Experience or nvidia.com/drivers
  • AMD: AMD Software or amd.com/support
  • Intel: Intel Driver & Support Assistant

3. Install DirectX and Visual C++

Required for the game to run properly:

  • DirectX 9.0c: Download from Microsoft
  • Visual C++ Redistributables (2005-2022): Download all versions

4. Disable Antivirus Temporarily

Some antivirus software flags game files as false positives. Temporarily disable during installation:

  • Windows Defender: Settings > Update & Security > Windows Security > Virus & threat protection > Manage settings > Turn off
  • Third-party: Right-click system tray icon > Disable/Pause
  • Re-enable after installation!

Step-by-Step Installation Process

Step 1: Download the Game

  1. Visit our download page
  2. Click the "Download Now" button
  3. Choose download server (select closest to your location)
  4. File size: 8GB (may take 20-60 minutes depending on internet speed)
  5. Save to a location you'll remember (Downloads folder is fine)

Step 2: Verify Download Integrity

Ensure the download wasn't corrupted:

  1. Check file size: Should be approximately 8GB
  2. Verify file extension: .rar or .zip
  3. Optional: Check SHA256 hash (advanced users)

Step 3: Extract the Archive

  1. Right-click the downloaded file
  2. Select "Extract Here" or "Extract to GTA San Andreas/"
  3. If prompted for password, check download page (ours has no password)
  4. Extraction takes 5-10 minutes
  5. Do NOT extract to Program Files (permission issues)

Recommended Installation Paths:

  • ✅ C:\Games\GTA San Andreas (recommended)
  • ✅ D:\Games\GTA San Andreas (if you have D: drive)
  • ✅ C:\Users\[YourName]\Games\GTA San Andreas
  • ❌ C:\Program Files\ (causes permission errors)
  • ❌ Desktop (clutters desktop and can be slow)

Step 4: Move to Final Location (Optional)

If you extracted to Downloads folder:

  1. Create new folder: C:\Games
  2. Cut (Ctrl+X) the extracted GTA San Andreas folder
  3. Paste (Ctrl+V) into C:\Games
  4. Final path should be: C:\Games\GTA San Andreas\gta_sa.exe

Step 5: Configure Compatibility Settings

Critical for modern Windows versions:

  1. Navigate to game folder
  2. Find gta_sa.exe (main game file)
  3. Right-click > Properties
  4. Go to "Compatibility" tab
  5. Check these boxes:
    • ✅ "Run this program as an administrator"
    • ✅ "Disable fullscreen optimizations"
  6. Click "Apply" > "OK"

Step 6: Create Desktop Shortcut

  1. Right-click gta_sa.exe
  2. Send to > Desktop (create shortcut)
  3. Rename shortcut to "GTA San Andreas" if desired
  4. Optional: Change icon (right-click shortcut > Properties > Change Icon)

Step 7: First Launch

  1. Double-click the game shortcut
  2. If Windows shows "Unknown Publisher" warning:
    • Click "More info"
    • Click "Run anyway"
  3. Game should launch to main menu
  4. First launch may take 30-60 seconds (creating configuration files)

Initial Game Configuration

Graphics Settings (First Time):

  1. From main menu: Options > Display Setup
  2. Set resolution: Your monitor's native resolution (e.g., 1920x1080)
  3. Aspect ratio: Wide Screen (for modern monitors)
  4. Draw distance: Start at 50-60% (adjust later)
  5. Visual FX: Medium (adjust based on performance)
  6. Anti-aliasing: Off (enable if you have good PC)
  7. Apply and restart game if prompted

Audio Settings:

  1. Options > Audio Setup
  2. Radio volume: 75% (or preference)
  3. SFX volume: 80%
  4. Set to stereo or 5.1 depending on your setup

Controls Setup:

  1. Options > Controller Setup
  2. Mouse sensitivity: Test and adjust (50-60% is good start)
  3. Invert mouse: Based on preference
  4. If using gamepad: Select "Joypad Configuration" and map buttons

Common Installation Issues & Solutions

Issue 1: "gta_sa.exe has stopped working"

  • Solution 1: Run as administrator (right-click > Run as admin)
  • Solution 2: Install DirectX 9.0c and VC++ Redistributables
  • Solution 3: Update graphics drivers
  • Solution 4: Disable DEP for gta_sa.exe

Issue 2: Black screen on launch

  • Solution 1: Update graphics drivers
  • Solution 2: Run in windowed mode (edit gta_sa.set file)
  • Solution 3: Disable second monitor temporarily
  • Solution 4: Set compatibility mode to Windows XP SP3

Issue 3: Missing .dll files

  • Solution: Install all Visual C++ Redistributables (2005-2022)
  • Download from Microsoft's official website
  • Install both x86 and x64 versions

Issue 4: Low FPS / Stuttering

  • Solution 1: Lower draw distance to 40-50%
  • Solution 2: Reduce resolution
  • Solution 3: Close background programs (Chrome, Discord)
  • Solution 4: See our low-end PC optimization guide

Issue 5: Save files not working

  • Solution: Ensure game has write permissions
  • Don't install in Program Files
  • Run as administrator
  • Check Documents\GTA San Andreas User Files exists
